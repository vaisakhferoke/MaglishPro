# Manglish Typing & AI Prompt Generator

A modern web application for Manglish to Malayalam transliteration, real-time English translation, and AI prompt engineering (Midjourney, ChatGPT, business emails, summaries, grammar refinement).

## Features
- **Manglish to Malayalam Transliteration**: Real-time phonetic suggestions powered by Google Input Tools and offline phonetic fallback.
- **English Auto-Translation**: Debounced translation with offline phrasebook fallback.
- **AI Prompt Templates**: Convert text into prompts for ChatGPT, Midjourney/DALL-E, formal emails, bullet summaries, and grammar polish.
- **Document & File History**: Multiple document management with local persistence.
- **Voice Typing**: Integrated speech-to-text recognition.
- **Dark Mode**: Complete theme toggle with adaptive UI.

## Tech Stack
- React 19
- Vite
- Lucide Icons
- Oxlint
